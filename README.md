# 🎓 Student Management System

A beginner Python project built using dictionaries, loops, conditions, sorting, and CRUD operations.

## Features

- 🔍 Search Student
- ➕ Add Student
- 👀 View Student Records
- ✏️ Update Student Details
- ❌ Delete Student
- 📊 Calculate Average Marks
- 🏆 Find Topper
- 📈 Rank Students

## Concepts Used

- Dictionary
- Nested Dictionary
- Loops
- If-Else
- CRUD Operations
- Sorting
- Lambda Function
- Enumerate
